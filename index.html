HACKNETOS // PACMAN REPOSITORY x86_64 GPG SIGNED
Arch Linux binary package repository for HacknetOS

01. Import Signing Key

Import and locally sign the HacknetAOS packaging key in the pacman keyring:

Fingerprint: 6D9D 481F 4ACB 997F 919B CA90 D906 9C15 6B0C 606C
Public Key: hacknetaos.asc | hacknetaos.gpg 
curl -fsSL https://hacknetaos.github.io/repo/hacknetaos.asc | sudo pacman-key --add -
sudo pacman-key --lsign-key 6D9D481F4ACB997F919BCA90D9069C156B0C606C

02. Configure /etc/pacman.conf

Append the repository block to /etc/pacman.conf:

[hacknetos]
SigLevel = Required DatabaseOptional
Server = https://hacknetaos.github.io/repo/$arch

03. Install HacknetOS

sudo pacman -Syu hacknet-os
